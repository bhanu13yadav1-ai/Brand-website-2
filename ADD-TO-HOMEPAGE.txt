BLACKED WELLNESS — separate-page upload guide

1. Extract blacked-wellness-v2.zip.
2. In the SAME published folder as your existing index.html, upload:
   - wellness.html
   - wellness.css
   - wellness.js
   - the whole assets/ folder and its image files
3. Add this navigation link into your existing index.html, inside #primaryNav:
   <a href="wellness.html">Wellness 18+</a>
4. Commit the changes, wait for GitHub Pages to publish, then open:
   https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/wellness.html

The new page is separate. Existing site files are not replaced by this package.

Features:
- screenshot-inspired black textured homepage and pink/purple style
- responsive category circles and product cards
- product search, category filters and sorting
- saved picks stored locally in the current browser
- compare up to two references side-by-side
- non-invasive comfort finder (no personal sexual history/photo inputs)
- product detail popups and responsive mobile navigation
- non-graphic product crops taken from the user's supplied screenshots

Important:
- Prices/discounts are copied from supplied screenshots as references, not live offers.
- These images are external-store screenshot references, not confirmed BLACKED stock.
- Verify current product identity, details, vendor, price, stock and image/commercial-use rights before public sales.
- No cart, checkout, payments, user accounts, reviews, live stock sync or backend have been connected.
