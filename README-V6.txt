BLACKED FINAL FUSION — V6 ADD-ON PACKAGE

This package adds a connected mobile-first experience for the existing Brand-website-full-finally- repository. It does not replace the original site.

NEW PAGES
- storefront.html — shared home with Innerwear, Sanskari Edit, Wellness 18+ and Boyfriend destinations
- sanskari-edit.html — campaign/lookbook gallery, searchable product-style cards, filters, sorting, saved styles, demo bag, manual overlay preview and campaign frame viewer
- wellness.html — 18+ self-attestation screen, non-graphic wellness-reference gallery, filters/search/sort, 2-item comparison, Comfort Finder and product-detail popup
- boyfriend.html — date planner, Hinglish message maker, copy action and conversation starters

NEW FEATURES
- Shared local-browser saved list and demo bag across the new pages
- Category tiles and pills, text search, sorting, detail popup and save/add interactions
- New generated still-life product visuals and individual campaign poster assets
- Transparent product cutouts for the manual style-layer preview
- A separate image-board gallery; each campaign image opens individually
- Mobile-responsive dark/pink branding, desktop layout, accessibility labels and reduced-motion handling
- Clear copy that sample prices/photos are references, not verified stock or offers

IMPORTANT: ORIGINAL FEATURES ARE PRESERVED
- The original index.html is deliberately excluded from this ZIP. Do not overwrite it.
- The target repository already contains boyfriend-cafe-01.webp through boyfriend-cafe-07.webp. Keep those original files; this package does not replace them.
- Existing Innerwear collection and Try-On Studio remain linked at index.html#collection and index.html#studio.

HOW TO INSTALL ON GITHUB PAGES
1. Download and extract this ZIP.
2. Open your target repo: https://github.com/bhanu13yadav1-ai/Brand-website-full-finally-
3. Make a backup of the repository first, especially index.html.
4. Upload the new HTML/CSS/JS files from the package to the repository root. Upload the entire assets/new-gallery/ folder with its filenames unchanged.
5. Do not upload/replace index.html from any package; this ZIP intentionally contains no index.html.
6. Open INDEX-NAV-PATCH.html. Copy those four links into the current main navigation while leaving the original nav links intact.
7. Optional: copy the section from INDEX-HOMEPAGE-ADDON.html into the existing index.html before the closing </main> if you want the new edit cards visible on the current homepage too.
8. Commit the files and check Settings → Pages. Wait for GitHub Pages to deploy, then check these pages on Android Chrome:
   /storefront.html
   /sanskari-edit.html
   /wellness.html
   /boyfriend.html

STATIC PROTOTYPE LIMITATIONS
- GitHub integration has read access but no push permission, so these files have not been committed/deployed automatically.
- No real account/login, payment, live inventory, order submission, tracking, actual bookings or admin analytics are connected.
- Saved items and bag use browser storage when available; fallback storage lasts only for the current page session.
- Wellness age gate is self-attestation, not formal age verification.
- The Fit Studio is a manual image-layering concept, not AI try-on, body measurement, sizing prediction or a fit guarantee.
- Product identity, supplier, prices, materials, measurements, safety certifications and commercial image rights must be verified before using any reference as a real product listing.
